# امضای نسخهٔ انتشار

نسخه‌های انتشار با کلید ثابت و از طریق GitHub Secrets امضا می‌شوند. کلید هرگز داخل مخزن قرار نمی‌گیرد.

- گواهی فعلی (از نسخهٔ 1.1.0): SHA-256 = `CF:57:F7:BC:B6:1B:5E:97:BE:A3:98:5B:24:41:BD:50:44:03:AA:CC:6A:F7:FE:CD:16:9E:4A:27:49:0F:79:B0`
- نسخه‌های 1.0.0 تا 1.0.17 با گواهی دیگری امضا شده‌اند، پس نسخهٔ 1.1.0 روی آن‌ها نصب نمی‌شود و باید اول اپ قبلی حذف شود.
- Secrets مورد استفاده: `ANDROID_RELEASE_KEYSTORE_B64`، `ANDROID_RELEASE_KEY_ALIAS`، `ANDROID_RELEASE_STORE_PASSWORD`، `ANDROID_RELEASE_KEY_PASSWORD`.
- ورک‌فلوی `Build Android APK` پس از ساخت، اثر انگشت گواهی APK را با `EXPECTED_CERT_SHA256` مقایسه می‌کند و اگر کلید دیگری استفاده شده باشد ساخت شکست می‌خورد.
- نام نسخه با `APP_VERSION_NAME` در `android/app/build.gradle.kts` تعیین می‌شود؛ `versionCode` از شمارهٔ اجرای ورک‌فلور می‌آید تا همیشه صعودی باشد.
- از کلید و رمزهایش یک نسخهٔ پشتیبان محرمانه نگه دارید؛ بدون آن انتشار نسخه‌های بعدی ممکن نیست.
